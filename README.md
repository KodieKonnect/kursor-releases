# Kursor

Useful actions at your pointer, for Mac. Select something in any app, three-finger click, and a small ring opens around the pointer to save, send, ask, capture or record.

**[Download the latest version](https://github.com/KodieKonnect/kursor-releases/releases/latest)** · [kursor.tech](https://kursor.tech)

Requires macOS 15 or later on Apple silicon. Open the downloaded `.dmg` and drag Kursor into Applications. Every release is signed and notarized by Apple.

Installed copies of Kursor check `appcast.xml` in this repository for updates.
